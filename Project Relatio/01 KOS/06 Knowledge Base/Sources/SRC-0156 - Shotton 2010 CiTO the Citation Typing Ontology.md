An ontology of the **nature of reference citations** — a large controlled vocabulary of citation-relationship types — and part of the **SPAR (Semantic Publishing and Referencing) ontology suite**.

# 2. Description (scope note — descriptive only)

An **ontology / vocabulary paper** defining typed citation relationships (e.g., factual and rhetorical relations between citing and cited works) for publication on the Semantic Web. It is about a **large typed citation vocabulary**; it is part of the SPAR suite. (Descriptive characterisation only — the note that the vocabulary is *large* is a description of its extent, not a quality judgement.)
